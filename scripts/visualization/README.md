# MIAOW BMI CSV Visualization

This folder contains lightweight plotting tools for MIAOW BMI output CSVs.

## Supported input format

`animate_bmi_csv.py` expects CSV files generated by the MIAOW BMI interface
(`BmiSimulationUnit`) and validates this schema:

- header starts with `time`
- remaining columns are exactly `val_0,val_1,...,val_N` in order
- one row per `Update()` step

If the header does not match this pattern, the script exits with an error.

## Environment setup

Assume commands are run from the repository root.

```bash
python3 -m venv scripts/visualization/.venv
scripts/visualization/.venv/bin/pip install -r scripts/visualization/requirements.txt
```

Dependencies are intentionally minimal and unpinned for low maintenance.

## Usage

1. Generate BMI CSV output:

```bash
./examples/01_heat/miaow_heat \
  --config ./examples/01_heat/configs/config_400x400.txt \
  --max_workers 1 \
  --task_request_timeout 30 \
  --job_request_timeout 300 \
  --output_root /tmp/miaow_vis_demo
```

2. Render MP4 from a task CSV:

```bash
./scripts/visualization/.venv/bin/python ./scripts/visualization/animate_bmi_csv.py \
  /tmp/miaow_vis_demo/run_1/job_1/task_0/plate_surface__temperature.csv \
  --output-dir /tmp/miaow_vis_demo/videos \
  --stride 1 \
  --fps 12 \
  --dpi 140
```

If your run/job/task IDs differ, locate CSV files with:

```bash
find /tmp/miaow_vis_demo -path '*/task_*/*.csv' | sort
```

3. Open the generated file:

```text
/tmp/miaow_vis_demo/videos/plate_surface__temperature.mp4
```

For long runs (e.g., SoilFreezeThaw), render directly with timestep stride:

```bash
./scripts/visualization/.venv/bin/python ./scripts/visualization/animate_bmi_csv.py \
  ./examples/02_soil_freeze_thaw/output/run_1/job_1/task_0 \
  --output-dir /tmp/miaow_soil_videos \
  --stride 96 \
  --fps 12 \
  --dpi 140
```

## ffmpeg behaviour

The script prefers the ffmpeg binary from `imageio-ffmpeg` in the venv. If that
is not available, it falls back to system `ffmpeg` on `PATH`.

## Requirements

- Python 3
- `numpy`
- `matplotlib`
- `imageio-ffmpeg`
